This is an enhanced version of an already existing Hollow Knight web port and adds
- A save manager allowing saves to be imported and exported accessible by pressing ALT+/
- A render scale slider allowing for better performance on lower spec machines like a Chromebook accessible by pressing ALT+.
- A FPS counter toggleable by pressing ALT+,

Other existing versions of the Hollow Knight web port have issues with Grimm and Nightmare King Grimm (Grimm becomes invisible after the first stagger and stops moving, and Nightmare King Grimm becomes invisible after the second stagger and cannot be hit, and the firebats are invisible apart from their particles on both fights). This version fully fixes Grimm making him able to be fought in full. Nightmare King Grimm still has issues, after the second pufferfish attack he will only use that move, making him unbeatable, but his firebats have been fixed. Nightmare King Grimm is still being worked on.
All enhancements are available by using hk-web-enhanced.html
